# Spanish Practice — span008

Practice six irregular Spanish verbs: ser, oír, estar, ir, tener, and decir.

Open `index.html` in a browser. No installation, build step, or server is required.

Uses the same layout and behavior as span007: definitions, a six-question definitions quiz, rules, conjugation examples, and a 20-question conjugation quiz. A perfect definitions score unlocks the last three lessons. Correct answers advance after two seconds; after an incorrect answer, select the highlighted correction to continue.

Includes English translation controls, three text sizes, keyboard navigation, and saved display preferences. Quiz progress is stored separately for span008.

- `index.html`: page structure, definitions, and rules.
- `styles.css`: layout and visual styling.
- `conjugations.js`: present-tense forms and bilingual examples.
- `app.js`: quizzes, navigation, and preference storage.
